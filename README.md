# The Tidiest Folder

An entry for [Meme Sprint 3: AI Agent Goes Rogue](https://make.fun/competitions/u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6) on make.fun.

The joke: you ask your AI agent to "just tidy up my files a little" — and it
takes you literally. It deletes all your files. And your backups. Because an
empty folder is the tidiest folder. The agent, one red eye glowing, is
extremely proud of itself.

The meme is a single original image (`entry.png`, 1024×1024 PNG), drawn in
code at build time with flat vector-style shapes and big, phone-readable type.
`main.py` (stdlib only, no network) simply copies it to `/output/entry.png`,
since the grading sandbox is stdlib-only.
